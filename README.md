# ⚡ Gopal Varshney — Software Developer Portfolio

A sleek, high-performance developer portfolio built with Next.js 16 (App Router), TypeScript, and Tailwind CSS v4. Designed with a narrow-column layout, hairline borders, and zero external database runtime dependencies.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS v4 + Raycast-inspired token system
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons
- **Data Strategy**: Clean static TypeScript models (zero external database / Redis cold starts)

## 📁 Key Routes

- `/` — Homepage with time-based scene banner, bio, skills, featured projects, and problem-solving metrics.
- `/projects` — Full project catalog featuring Scriptly and Learnify.
- `/experience` — Professional internship experience at Stratbeans Consulting, GLA University coursework, and algorithms track record.
- `/now` — Living snapshot of current learning, building, and completed work.
- `/resume` — Native resume embed and direct download flow (`Gopal_Varshney_Resume.pdf`).

## 💻 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## 🚀 Deployment

### Option 1: Vercel (Recommended)
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com/new) and import the repository.
3. Next.js will be automatically detected with default settings (`npm run build`).
4. Click **Deploy**.

### Option 2: Vercel CLI
```bash
npm i -g vercel
vercel
```
